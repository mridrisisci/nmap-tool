# nmap-tool

## General
This is a Nmap-like tool in its early stage. 

As per this date, the tool is able to recieve a target to scan and recieve a port range in which the tool then does what Nmap would do
1. Banner grabbing
2. Check open ports in the specified port range
3. Show which ports are open/closed

## Usage
To use recieve a help menu you must execute the tool e.g in your CLI and use the '--help' flag to see available options. 

## Development
This tool is will periodically be upgraded with more advanced features.
